# Design critique: SnoreNudge (Wear OS), 2026-11-03

Source: JVM-rendered screenshots in `docs/design/current/` (450x450 round, Galaxy Watch4 Classic 46 mm).
Context: used at night, in the dark, half asleep. Every screen must be readable at a glance and must not light up the bedroom.

## Overall impression

The dark navy + teal + amber palette is calm and coherent, icons are consistent (Material Rounded), and the running ring reads well. The biggest problems are night-time glare from the large filled Start button and several pieces of text that are clipped by the round screen or wrap badly.

## Usability

| Finding | Severity | Recommendation |
|---|---|---|
| Running Home: snores / nudges counters sit at the bottom edge and are clipped by the circle ("nores", "nu...") | Critical | Move both counters inside the ring, under "until 07:30", as one compact row |
| Setup: permission labels clipped ("Micropho", "Notificati") | Critical | Smaller label style, allow 2 lines, shorter labels ("Mic", "Alerts", "Battery") |
| Night detail: legend "delay" wraps one letter per line | Critical | Legend as a centered 2-line block or drop the delay entry and shade only |
| Night detail: busiest periods time range cut ("02:02-02:1"), nudge levels cut ("L1 4 / L2 3 / L3") | Moderate | Show start time only ("02:02") with "10 min" implied; levels as three small pills |
| History summary: "36 avg / 6.3 avg / 28 night" is ambiguous | Moderate | Units in labels: "36 min", "6.3 nudges", "28 nights" |
| Titles of History and Night detail start under the clock at the initial scroll position | Moderate | Header item first, centered initially, with proper top spacing |
| Start button is a large solid teal disk: very bright on OLED at night | Moderate | Tonal button: dark teal fill, teal ring, teal play icon and label |

## Visual hierarchy

- What draws the eye first: the Start disk (idle) and the elapsed time (running). Correct.
- Running: the secondary information (snores, nudges) is what the user checks in the morning and is currently the least visible. Bring it into the ring.
- Section screens mix header styles: Settings, Live test and Setup use icon above title; History uses a small inline title; Night detail has none. Use one header pattern everywhere.

## Consistency

| Element | Issue | Recommendation |
|---|---|---|
| Screen headers | Three different patterns | One `ScreenHeader(icon, title, subtitle?)`: icon above title, title in titleMedium |
| Stat tiles | History uses bare numbers + "avg", Night detail uses tiles with units | One `StatTile(icon, value, unit)` used on both |
| Number formatting | "121 snore" vs "121 min snoring" | Value + short unit everywhere ("121 snores", "121 min") |
| Accent use | Teal used for both interactive and data | Keep teal for data and primary action; interactive secondary buttons stay neutral surface |

## Accessibility

- Contrast: primary text #E6EAF0 and secondary #9AA4B2 on #0B0F17 pass WCAG AA (well above 4.5:1). Amber on dark passes. Teal on the solid teal button (dark text) passes, but the tonal version must keep the label at least 4.5:1.
- Touch targets: list buttons are 52 dp or more. Picker radio rows are fine.
- Readability: chart axis labels are small but acceptable; legend must not wrap.

## What works well

- Calm, premium palette that suits a bedtime app.
- Clear iconography, no emoji, consistent Rounded icon family.
- Running ring with large elapsed time is glanceable.
- Picker screens and Settings list are clean and easy to scan.

## Priority recommendations

1. Running Home: counters inside the ring (fixes the most important clipped info).
2. Fix all clipped / wrapped text (Setup labels, legend, busiest periods, nudge levels, history units).
3. Night-friendly Start: tonal instead of solid teal; keep the same size and centering.
4. Unify headers and stat tiles across History, Night detail, Settings, Live test, Setup.
